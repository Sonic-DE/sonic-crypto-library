# Sonic Crypto Library Release Notes

Sonic Crypto Library provides the encryption and security features that SonicDE apps rely on to keep your data safe.

## 2.3.12 (2026-08-24)

- Behind the scenes: dropped the need for older Plasma and Qt 5 support libraries when building, and made installed files use relative locations by default.

## 2.3.10 (2026-07-14)

- Behind the scenes: restored the code formatting settings and added support for developers' code-navigation tools.
